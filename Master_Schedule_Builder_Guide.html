สำหรับผู้ใช้งาน

ทีมงานทุกคนที่ต้องกรอกแผน อัปเดตความคืบหน้า และบันทึก Defect

1. เริ่มใช้งานครั้งแรก getting started

  1. 1
    เปิดลิงก์ด้วย Chrome หรือ Microsoft Edge บันทึกลิงก์ไว้ในบุ๊กมาร์ก ใช้ได้ทั้งคอมพิวเตอร์และแท็บเล็ตหน้างาน
  2. 2
    กด โหมดทีม (M365) เพื่อเข้าใช้ข้อมูลกลาง ใส่ อีเมลบริษัท และ รหัสทีม ที่ได้จากผู้ดูแล (ขึ้นต้นด้วย MSB1-) — ใส่รหัสครั้งเดียว ครั้งต่อไปเหลือแค่อีเมล
  3. 3
    เครื่องที่ล็อกอิน Microsoft 365 อยู่แล้วจะเข้าเงียบ ๆ ถ้าไม่ใช่ จะมีหน้าต่างของ Microsoft เด้งมาให้ใส่รหัสผ่าน โดยเติมอีเมลไว้ให้แล้ว
  4. 4
    ดูแถบสถานะใต้หัวเรื่อง สีเขียว = เชื่อมข้อมูลกลางแล้ว · สีแดง = มีคนอื่นกำลังแก้อยู่ (หน้าคุณเป็นโหมดอ่าน) · ไม่มีแถบ = ยังไม่ได้เข้าโหมดทีม

2. กรอกแผนงาน 5 ขั้น build the schedule

  1. 1
    ตั้งค่าโครงการชื่อโครงการ · วันเริ่มงาน · ระยะเวลาสัญญา · เลือกวันทำงาน (จ.–ส. / จ.–ศ. / ทุกวัน) · ใส่วันหยุดพิเศษเป็น 2026-04-13 คั่นด้วยลูกน้ำ
  2. 2
    เลือกเทมเพลตเทมเพลตงาน → ฉบับ A งานอาคาร (WP-01…13) หรือ ฉบับ B บ้าน (B-1…8) มีช่วงรอ Main Contractor ปิดฝ้าคั่นให้แล้ว
  3. 3
    แก้รายการงานพิมพ์ทับได้เลย · ชื่องาน/รหัส WBS/ผู้รับผิดชอบ เลือกจากรายการที่มีให้ · ปุ่มท้ายแถว ↑ ↓ เลื่อน · ⧉ ทำซ้ำ · ✕ ลบ
  4. 4
    กด คิดน้ำหนักอัตโนมัติเกลี่ยน้ำหนักตามจำนวนวันให้ครบ 100% แล้วปรับงานที่มีมูลค่าสูงเพิ่มเอง
  5. 5
    อัปเดตทุกสัปดาห์ใส่ช่อง ทำแล้ว % ของแต่ละงาน แถบ KPI จะบอกทันทีว่าแผน ณ วันนี้กี่ % ทำได้จริงกี่ % ช้ากว่าแผนเท่าไร

3. ช่องไหนต้องกรอก ช่องไหนไม่ต้อง what to fill in

  • ช่องพื้นเหลืองขอบทอง = ต้องกรอก ยังว่างอยู่ · พอกรอกแล้วสีหายเอง
  • ช่องพื้นเทา = ระบบคำนวณให้ (วันเริ่ม / วันเสร็จ) ไม่ต้องไปยุ่ง
  • จุดแดงท้ายชื่อช่อง ในข้อมูลโครงการ = ช่องบังคับ
  • ป้ายที่หัวตาราง บอกว่ายังเหลือกี่ช่อง กดแล้วกระโดดไปช่องนั้นให้เลย · กรอกครบเปลี่ยนเป็นป้ายเขียว
  • บังคับกรอกจริง ๆ มีแค่: ชื่อโครงการ · วันเริ่มงาน · ระยะเวลาสัญญา · ชื่องาน · จำนวนวัน
  • อยากให้ตารางเรียบง่ายขึ้น เลือก มุมมอง → ง่าย จะเหลือเฉพาะช่องที่ต้องกรอก

4. คอลัมน์ที่ต้องเข้าใจ columns

เริ่มหลังจากงานที่ต้องเสร็จก่อน — ตัวที่ทำให้แผนทั้งสายเลื่อนตามกัน
ชนิดFS เริ่มหลังงานก่อนเสร็จ · SS เริ่มพร้อมกัน
Lagเว้นกี่วันทำงาน · ใส่ติดลบได้ ถ้าต้องการให้งานคาบเกี่ยวกัน
วันระยะเวลา นับเฉพาะวันทำงาน ข้ามวันหยุดให้เอง
น้ำหนัก%สัดส่วนของงานนั้นในโครงการ รวมทุกงาน = 100%
ทำแล้ว %ความคืบหน้าของงานนั้นเอง 0–100 (เสร็จแล้ว = 100)
MSติ๊ก = Milestone / Hold Point ★ แสดงเป็นข้าวหลามตัดแดง
รอผู้อื่นช่วงที่เราไม่ได้ทำ เช่นรอปิดฝ้า — กินเวลาแต่ ไม่นับน้ำหนักและผลงาน
ข้อผิดพลาดที่พบบ่อยที่สุด — "ทำแล้ว %" ไม่ใช่ "น้ำหนัก%" งานที่เสร็จแล้วให้กรอก 100 ไม่ใช่กรอกน้ำหนักของมัน (เช่น 7.6) ระบบจะคูณน้ำหนักให้เอง ถ้ากรอกผิดแบบนี้ แท่ง Gantt จะเติมสีนิดเดียวและ KPI ผลงานจริงจะต่ำผิดปกติ — เครื่องมือตรวจจับให้และขึ้นปุ่ม “แปลงให้อัตโนมัติ” กดครั้งเดียวแก้ทั้งตาราง

5. บันทึกและติดตาม Defect defects

  • กด + เพิ่ม Defect — ระบบเติมให้อัตโนมัติ: วันที่วันนี้ · งานที่กำลังทำ · รหัส WP · ผู้แก้ไข
  • กำหนดแก้คิดให้ตามมาตรฐาน — Critical = วันทำงานถัดไป · Major = วันเสร็จของ WP นั้น · Minor = วันส่งมอบ (แก้ทับได้)
  • แถวขีดแดงซ้าย = เกินกำหนดแก้ · ขีดเหลือง = Critical ที่ยังค้าง
  • งานที่มี Defect ค้างจะขึ้นตรา ▲ ตัวเลข ใน Gantt · คลิกที่ตราเพื่อกรองดูเฉพาะงานนั้น
  • เปลี่ยนสถานะเป็น Verified / Closed แล้วระบบลงวันที่แก้เสร็จให้เอง
  • กฎที่ระบบเตือนให้: ห้ามผ่าน Hold Point ★ ถ้ายังมี Defect ค้าง · กรอกทำแล้ว 100% ทั้งที่ยังมี Critical ค้าง · Defect เกินกำหนดแก้

8. ทำงานพร้อมกันหลายคน working together

  • ระบบดึงของใหม่จากไฟล์กลาง ทุก 20 วินาที และบันทึกของคุณให้เองหลังหยุดพิมพ์ 2–3 วินาที

  • ให้แต่ละคนแก้คนละโครงการ (คนละแท็บด้านบน) จะไม่ชนกันเลย

1. ข้อมูลถูกเก็บไว้ที่ไหน architecture

เบราว์เซอร์ของแต่ละคนที่เก็บชั่วคราว ใช้ได้ทันทีโดยไม่ต้องตั้งอะไร — ล้างประวัติแล้วหาย
ไฟล์ถาวรในเครื่องปุ่ม เชื่อมไฟล์ถาวร ผูกกับไฟล์ .json จริง (แนะนำวางใน OneDrive) ทุกการพิมพ์เขียนลงไฟล์เอง — เหมาะกับคนที่ทำแผนของตัวเอง
ไฟล์กลางของทีมโหมดทีม (M365) — ไฟล์ .json ไฟล์เดียวบน OneDrive/SharePoint ที่ทุกคนอ่าน-เขียนผ่าน Microsoft Graph นี่คือแหล่งข้อมูลจริงของทีม

2. ติดตั้งครั้งแรก one-time setup

  1. 1
    ลงทะเบียนแอปใน Microsoft Entra เข้า entra.microsoft.com ด้วยอีเมลบริษัท → App registrations → New registration → ตั้งชื่อ Master Schedule Builder
  2. 2
    ตั้ง Redirect URI ชนิด SPA เลือก Single-page application แล้ววาง https://wyuwachotiphan-crypto.github.io/CM-Dashborad/Master_Schedule_Builder.html
  3. 3
    ให้สิทธิ์ Microsoft Graph API permissions → Add a permission → Microsoft Graph → Delegated → Files.ReadWrite.All และ User.Read
  4. 4
    คัดลอกค่า 2 ตัวจากหน้า Overview Application (client) ID และ Directory (tenant) ID
  5. 5
    สร้างไฟล์กลาง สร้างไฟล์ ERV_Master_Schedule.json ในโฟลเดอร์ Teams/SharePoint ที่ทีมเข้าถึงได้ ใส่ข้อความ {"projects":[]} ไว้ข้างใน แล้ว Share → คัดลอกลิงก์ ตั้งสิทธิ์เป็น People in Coral Life · แก้ไขได้
  6. 6
    กรอกในเครื่องมือแล้วสร้างรหัสทีม เปิดเครื่องมือ → โหมดทีม (M365) → ใส่อีเมลผู้ดูแล ส่วนตั้งค่าจะโผล่ → กรอก 3 ค่า → กด สร้างรหัสทีม → คัดลอกรหัสส่งให้ทีมทางไลน์

3. เพิ่ม–ถอนคนในทีม access

  • เพิ่มคน: ให้สิทธิ์เขาที่ไฟล์กลางใน SharePoint/OneDrive แล้วส่งรหัสทีมให้ — เขาใส่อีเมล + รหัสครั้งเดียว
  • ถอนคน: เอาสิทธิ์ที่ไฟล์ออก คือสิ่งที่ได้ผลจริง เพราะ Microsoft ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ — ต่อให้เขายังมีรหัสทีมก็เปิดข้อมูลไม่ได้
  • รหัสทีมเป็นเพียงตัวช่วยตั้งค่า ไม่ใช่รหัสผ่าน — สิทธิ์จริงอยู่ที่ไฟล์เสมอ
  • อยากให้ทีมไม่ต้องใส่รหัสเลย ให้ฝังค่าทั้ง 3 ลงในไฟล์เครื่องมือแล้ว push ขึ้น GitHub (ดูข้อ 5)

4. ดูแลข้อมูล data care

  • สำรองข้อมูล: กด สำรองทุกโครงการ ทุกสิ้นสัปดาห์ ได้ไฟล์ .json รวมทุกแท็บ เก็บไว้ในโฟลเดอร์โครงการ
  • กู้คืน: เปิดไฟล์ แล้วเลือกไฟล์สำรอง — ระบบถามก่อนแทนที่ทุกโครงการ
  • ส่งเฉพาะโครงการเดียว: บันทึกโครงการนี้ ได้ไฟล์เดียว ผู้รับกด เปิดไฟล์ จะเข้าเป็นแท็บใหม่ ไม่ทับของเดิม
  • ล็อกค้าง: ล็อกหมดอายุเองใน 2 นาที ถ้ายังค้างจริง ๆ ให้คนที่ถือล็อกเปิดหน้าแล้วปิด หรือแก้ค่า lock ในไฟล์กลางออก
  • ข้อมูลชนกัน: ระบบตรวจเวอร์ชันไฟล์ก่อนเขียนทุกครั้ง ถ้าไฟล์ใหม่กว่าจะถามก่อน ไม่เขียนทับเงียบ ๆ

5. อัปเดตตัวเครื่องมือ deployment

  • ไฟล์ต้นฉบับอยู่ที่ Desktop\Dashboard\Master_Schedule_Builder.html — แก้ไฟล์นี้ไฟล์เดียว
  • ดับเบิลคลิก Update Dashboard to GitHub.bat เพื่อส่งขึ้นเว็บ (พาคู่มือขึ้นไปด้วย) ขึ้นจริงภายใน 1–2 นาที
  • บอกทีมให้กด Ctrl+F5 หลังอัปเดต เพื่อล้างแคชเบราว์เซอร์
  • ข้อมูลของทีมอยู่คนละที่กับตัวเครื่องมือ — อัปเดตเครื่องมือไม่กระทบข้อมูล
ข้อจำกัดและความปลอดภัยที่ต้องรู้ เว็บที่วางเครื่องมือเป็นพื้นที่สาธารณะ ใครมีลิงก์เปิดหน้าเครื่องมือได้ แต่เปิดข้อมูลไม่ได้ถ้าไม่มีสิทธิ์ที่ไฟล์กลาง โหมดทีมต้องใช้อินเทอร์เน็ต — ถ้าเน็ตล่ม เครื่องมือยังทำแผนได้ตามปกติ เพียงแต่ไม่ซิงก์กับทีม ต้องใช้ Chrome หรือ Edge สำหรับปุ่มเชื่อมไฟล์ถาวรและโหมดทีม
