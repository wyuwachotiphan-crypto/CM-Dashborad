Start Date / End Date = the planned schedule window for that phase · Actual Start Date / Actual End Date = when that phase actually started/finished on site (leave blank if not finished yet) — together these power the Planned vs Actual schedule chart on each project's detail popup · Delivery Date = the contractual handover/delivery date to the client · Actual Delivery Date = the date the project was actually handed over — one value per project (same for every phase row of that project)

Project Type = Internal (งานภายในองค์กร) or External (งานก่อสร้างภายนอก) — powers the Type filter on the Projects list · Cash Advance (THB) = the project's allocated petty cash float · Collected (THB) = payment already collected from the client/owner · Man Power (Hours) = cumulative site-inspection hours · Site Visit Days = number of days a site visit was conducted · Site Inspector = name of the person who carried out the site visit · Preliminary = preliminary/general site cost item · VO = Variation Order, value of additional work · VE = Variation/Omission, value of reduced or omitted work · Contractor Name = the main contractor engaged for the project (use "Not Yet Awarded" if not yet contracted) · Contract Value = the awarded contract sum for that contractor · Master Schedule PDF = a direct link (SharePoint/Google Drive/GitHub, etc.) to that project's Master Schedule PDF — shown as a "View Master Schedule (PDF)" button on the project detail popup, leave blank if none · BD Data Received Date = the date the Business Development team reported/received this project's financial figures — shown in the Financial Overview breakdown popup

The Status column accepts: Construction / Completed / Planning / On Hold · the Project Type column accepts: Internal / External / Non-Project (defaults to External if left blank) — Project names in the Master Schedule must match exactly with names in the Summary Report so the system can correctly link the two sheets.

A row with Project Type = Non-Project is excluded from Total Projects, the Projects list, and every other project-level total — only its Cash Advance (THB) value is added into the portfolio-wide Cash Advance total on the Contract Variations chart. Use this for Cash Advance amounts that aren't tied to any specific project in the database.

Sheet: Site Visit Log (optional — 1 row = 1 site visit)

Visit DateProject NameInspector NamePurposeSite Visit Hours

Powers the Monthly Site Visit Overview chart — a team-wide view of off-site work execution by month, in hours. Add one row per visit (one team member, one site, one day). Visit Date = the exact day of the visit · Project Name = which project/site was visited (leave blank if not tied to a specific project) · Purpose = what the visit was for (e.g. Progress Inspection, Safety Audit, Client Walkthrough) — click a bar on the chart to see each visit's date, project, inspector, and purpose. If this sheet is missing, the chart will simply show no data.
